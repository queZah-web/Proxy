# بروكسي تليجرام سريع (MTProto + Fake-TLS)

بروكسي تليجرام رسمي النوع (MTProto) يعمل بتقنية **Fake-TLS**، فيبدو للشبكة كأنه اتصال HTTPS عادي إلى موقع معروف، وهذا يصعّب حجبه.
المحرك المستخدم هو [mtg v2](https://github.com/9seconds/mtg)، وهو مكتوب بلغة Go وخفيف وسريع جداً. مع السكربت يتم تفعيل **BBR** وتحسينات TCP لتقليل التأخير.

## المتطلبات
- سيرفر VPS بنظام لينكس (Ubuntu أو Debian مفضّل) **موجود خارج الدولة التي تحجب تليجرام**
- صلاحيات root

> 💡 السرعة تعتمد قبل كل شيء على **موقع السيرفر**. اختر سيرفراً قريباً منك جغرافياً، مثل ألمانيا أو هولندا أو تركيا أو الإمارات لمستخدمي الخليج والشرق الأوسط، ويُفضّل أن يكون قريباً من سيرفرات تليجرام في أوروبا (أمستردام).

## التثبيت (أمر واحد)
```bash
git clone https://github.com/queZah-web/Proxy.git && cd Proxy
sudo bash install.sh
```

اختيارياً تحدد المنفذ والدومين المستخدم للتمويه:
```bash
sudo bash install.sh 443 www.cloudflare.com
```

في النهاية يطبع لك السكربت رابطاً بهذا الشكل:
```
https://t.me/proxy?server=1.2.3.4&port=443&secret=ee....
```
افتحه من جوالك واضغط **Connect** وسيضاف البروكسي لتليجرام تلقائياً.

## أوامر مفيدة
| الأمر | الوظيفة |
|---|---|
| `cat /opt/mtg-proxy/link.txt` | عرض رابط البروكسي |
| `docker logs -f mtg-proxy` | عرض السجلات |
| `docker restart mtg-proxy` | إعادة التشغيل |
| `sudo bash uninstall.sh` | حذف البروكسي |

## نصائح للسرعة وتجنّب الحجب
- استخدم المنفذ **443**، فهو الأقل عرضة للحجب.
- لو انحجب البروكسي، غيّر الدومين المستخدم للتمويه: احذف الملف `/opt/mtg-proxy/secret` ثم أعد تشغيل `install.sh` بدومين آخر.
- لا تنشر الرابط علناً، فانتشاره يسرّع حجبه.
- تأكد من فتح المنفذ في جدار الحماية الخاص بمزود السيرفر (Security Group).
